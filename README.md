# Scan2MD

Convert **scanned (image-only) PDFs** — where you can't select the text —
into Markdown, preserving reading order, layout position, and embedding
any pictures/figures inline as compressed base64 images.

## How it works

1. Each PDF page is rasterized to a high-DPI image with **pypdfium2** (no
   text layer needed — this works purely on the image).
2. The page image is sent to Gemini (`gemini-3.6-flash`) with a prompt that
   returns a structured JSON list of content blocks (heading / paragraph /
   table / figure), each with a **normalized 0–1000 bounding box**
   (Gemini's native coordinate format).
3. For every `figure` block, the real pixels are cropped directly from the
   rasterized page (never regenerated by the model), downscaled to a max
   width of 700px, and JPEG-compressed before base64-encoding — this keeps
   the final `.md` file small.
4. Each page is rendered as a single block of **absolutely-positioned HTML,
   embedded directly inside the Markdown file** — headings, paragraphs,
   tables, and images are placed using the same bounding boxes Gemini
   returned, so the layout visually matches the original scan as closely
   as a `.md` file can.

> **Note on fidelity:** Markdown itself is a linear format and can't hold
> true x/y position — but Markdown files can contain raw HTML, and most
> renderers (VS Code's Markdown preview, GitHub, browsers, Notion) render
> that HTML. So opening the `.md` file in one of those will show a layout
> close to the source PDF page. Opening it in a plain text editor or a
> strict markdown-only renderer will show the raw positioned `<div>` tags
> instead — that's an inherent property of Markdown, not a bug.

## Setup

```powershell
cd scan2md
py -3.12 -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt

$env:GEMINI_API_KEY = "your-key-here"
python app.py
```

Then open **http://localhost:5000** in your browser.

(macOS/Linux: `python3 -m venv venv`, `source venv/bin/activate`,
`export GEMINI_API_KEY="your-key-here"`)

## Usage

1. Drop or select a scanned PDF.
2. Click **Convert to Markdown**.
3. View the **Preview** tab (renders the positioned layout) or the
   **Raw Markdown** tab, and download the `.md` file — it's a single
   self-contained file with images embedded inline.

## Notes / limits

- Works best on single-column and simple multi-column layouts. Very dense
  or heavily stylized layouts may need prompt tuning in `BLOCK_PROMPT`
  inside `app.py`.
- Each page = one Gemini API call, so large PDFs will take a while and use
  more quota.
- The uploaded PDF is processed entirely in memory (never written to disk),
  so there's no cleanup step and no Windows file-lock issues.
- No database — conversions are stateless per request.

## Troubleshooting

**"Unable to find Visual Studio" / build errors during `pip install`**
Some packages don't yet publish prebuilt wheels for very new Python
versions (e.g. 3.14), so pip tries to compile from source. This project
avoids that for PDF rendering by using `pypdfium2` instead of PyMuPDF. If
another package hits this, either upgrade its version pin in
`requirements.txt` to the newest release, or install Python 3.12 instead
(`py -3.12 -m venv venv`), which has full wheel coverage for every
dependency here.

**`GEMINI_API_KEY environment variable is not set`**
Set it in the same terminal window before running `python app.py`:
```powershell
$env:GEMINI_API_KEY = "your-key-here"
```
